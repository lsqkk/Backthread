# 架构说明

应用界面由 WinUI 3（Windows App SDK）原生控件构成。发布时应用与 .NET、Windows App SDK 一并部署，不依赖应用商店或 MSIX 证书。

- `NativeDesktop.cs` 以 Win32 `SetWinEventHook` 接收前台切换，屏蔽自身和系统界面；注册两个系统级快捷键。按原系统规则请求前置或还原目标窗口。
- `Trail.cs` 管理单调时钟下的有界轨迹、回访筛选和手动检查点，不涉及 UI 或文件系统。候选筛选在读取时再次判断目标是否存活。
- `MainWindow.xaml(.cs)` 处理用户交互、持续时长、空闲检测和可读反馈。`GetLastInputInfo` 仅判断系统最近有无输入，不读取具体按键。每秒检查当前窗口标题变化，空闲超时或计时器长时间未调度时断开记录，避免把休眠算作持续处理窗口。
- 同一个窗口在标题变化后仍携带应用赋予它的进程内随机命名的 Win32 属性。检查点同时验证窗口句柄、进程 ID 和属性值，避免把复用句柄或同名新窗口错认成旧目标。若系统不允许设置属性，回线跳过该窗口。无跨会话持久化。
- 窗口切换受到 Windows 前台规则约束。回线不伪造键鼠输入来绕过限制；成功回到原窗口时，才自动移除已恢复的检查点。
- 进程退出时注销监听、快捷键，清理窗口属性并释放所有内存记录。安装器为当前用户写入应用文件、开始菜单入口及卸载登记。

回线不尝试还原应用内部状态、未保存文档、浏览器标签或跨登录会话的内容。它只帮你找回还在运行的那扇窗口。更多范围定义与竞品对照见 [选题与调研](research.md)。
