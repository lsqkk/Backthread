# 产品与架构

回线处理跨过多次窗口切换后的返回。按 `Ctrl+Alt+J` 直接切换。有明确回访目标时，离开前按 `Ctrl+Alt+K` 标记当前窗口。标记只有一个，显示在最近窗口列表里，返回成功后清除。

- `Trail.ReturnTarget` 依次选择仍可用的标记、最近 15 分钟内停留至少 45 秒的窗口、最近访问的其他窗口。
- `NativeDesktop` 使用 WinEvent 跟踪前台，并在收到系统快捷键消息时请求目标窗口进入前台。目标通过 HWND、PID 和窗口属性验证。仅在确认原窗口成为前台后清除标记。
- WinUI 工作台从托盘或开始菜单打开，提供最近窗口搜索、设置和关于页。本地 JSON 只保存设置，会话记录和标记都在内存中。
- 启动项使用 `Backthread.exe --background`。卸载会移除该项。Actions 构建发布包，应用通过 GitHub Releases 的稳定版接口检查更新。
