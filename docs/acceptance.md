# 回线 Backthread：手工验收

本页是可重复执行的验收步骤，不代表测试结果。优先使用日常 Windows 账户和发布版安装器；如机器还安装了开发版，先退出它。使用空白文档及测试笔记，避免在截图或日志里留下个人数据。

## 五分钟主流程

1. 用安装包按默认位置安装。从开始菜单启动回线。确认能看到轨迹和返回点，系统没有索要额外权限。若系统展示发布者或信誉提示，记下实际提示和安装包的签名状态。把主窗口最小化，保持回线在运行。
2. 准备三个独立窗口：记事本 A、计算器 B、资源管理器 C。先打开 A，在空白文档输入 `工作线 A`，保持前台约一分钟（超过默认 45 秒）；再到 B、C 各停两三秒。按 `Ctrl+Alt+J` 打开回线，确认轨迹按真实顺序展示 A → B → C，A 的停留明显较长，回线自己没有混进数据。
3. 检查自动返回候选。应提议上一段较长停留的 A，并能解释或显示其停留线索。使用返回动作，应把 A 的**原窗口**带到前台，`工作线 A` 仍在，未多开一个记事本。故意把较长时间花在另一个窗口时，候选可能变化；从轨迹中手动选择 A 仍应可行。
4. 在 A 按 `Ctrl+Alt+K` 添加返回点（可留便签 `继续第三段`）。切到 B 再添加一层（便签 `核对总数`），然后切到 C。打开回线，应看见两层以及各自的窗口和笔记。第一次返回到 B，只消耗上层；第二次返回到 A，栈回到空态。测试时先看清窗口身份再确认操作。

## 边界与回归

| 编号 | 检查 | 步骤与通过条件 |
| --- | --- | --- |
| W1 | 同一个应用的两个窗口 | 开两个独立的记事本窗口，分别写 `左` 和 `右`。先后切换并留点；由轨迹或返回点唤起的必须是对应实例。两个窗口使用相同标题时，不能仅靠标题或应用名重找窗口。 |
| W2 | 同一窗口出现两次 | 用 A → B → A → C 的顺序，每次停一两秒。可以在轨迹中读出两次 A，不能缩成 `Alt+Tab` 的唯一窗口列表。 |
| W3 | 最小化 | 给 A 留点，再最小化 A。从正常权限的 B 返回，应恢复最小化并聚焦 A。原有文本不变。 |
| W4 | 原窗口已关闭 | 给 A 留点后关闭 A；另开一个相同应用窗口。尝试回到原点，应明确提示原窗口失效或在界面标记为不可用，并保留栈条目供手动舍弃。不能启用新窗口、无声跳到另一窗口或主动启动应用。 |
| W5 | 前台请求被系统拒绝 | 有条件时，检查不同权限、其他虚拟桌面或窗口正在关闭的场景。回线不跨虚拟桌面激活；请求被拒时要如实反馈，不能显示成功却停留在不对应的窗口，也不可让面板无响应。 |
| W6 | 空态与短停留 | 首次运行或清除轨迹之后，检查没有可用候选时的状态。只做几次极短切换，验证不足 45 秒的段不会成为长停留候选，不应把刚打开的回线本身识别为默认返回目标。 |
| W7 | 空闲与记录上限 | 将 A 保持前台且至少三分钟不输入，再切到 B；超过两分钟的空闲时长不应继续计入。重复切换超过 60 段，确认轨迹容量有界；较早段达到 15 分钟后不应再参与自动返回候选。 |
| S1 | 笔记与选择 | 分别保存空笔记和中文笔记。若界面提供编辑或删除，先留两层，再修改/删除指定项，验证未选项不受影响。 |
| S2 | 栈容量 | 连续建立返回点，确认最多保留 12 层。尝试第 13 层时，记录界面反馈；确认已有返回点不会无声乱序。 |
| K1 | 全局快捷键 | 分别用 `Ctrl+Alt+J`、`Ctrl+Alt+K` 从记事本和计算器触发；按住快捷键数秒，观察是否意外重复留下多个返回点或弹出多个窗口。若组合键被其它工具占用，界面应有可识别的失败状态或可用的鼠标操作。 |
| P1 | 记录边界 | 在回线窗口里停留，确认不记入外部轨迹。最小化后访问 A，再打开确认 A 有记录。暂停后切换 A → B → C，再恢复；暂停期间访问不应新增轨迹，暂停也不应消耗已有返回点。用清除命令单独核对清理作用域。 |
| P2 | 本地和隐私 | 开一个有独特假标题的窗口并添加假笔记，用于区分允许出现的窗口元数据与不应采集的正文、剪贴板或截图。关闭回线主窗口，应退出并停止记录；重启后旧轨迹和旧返回点不应恢复。 |
| U1 | 安装与卸载 | 在备用账户或测试环境中，从 Windows「安装的应用」卸载。验证开始菜单项、程序文件及进程的处理符合文档；记录本地数据是保留还是清除。之后再次安装并启动，确认没有依赖开发工具。 |
| U2 | Windows 常用显示模式 | 浅色、深色、125% 缩放各检查一次；窄化窗口，验证标题、中文笔记、候选和按钮可读。只用 `Tab`、方向键及 `Enter` 完成一次返回；高对比度和屏幕阅读器可额外记录。 |
| U3 | 文件占用与重装 | 让已安装的回线保持运行，再打开安装包。覆盖安装时允许安装程序正常关闭回线，确认更新后可重新启动且没有重复的应用条目。运行回线时再次尝试卸载，应先收到关闭提示，取消后应用仍可用；退出回线后重试应能卸载。 |

验收记录建议包含：Windows 版本和架构、安装包文件名与 SHA-256、当前配置、通过的测试编号，以及每个失败的复现步骤和实际现象。多显示器、其他虚拟桌面及高权限窗口只在相应环境真实验证后记为通过。
