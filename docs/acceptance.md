# 1.1.1 桌面验收

1. 关闭工作台。从 A 切到 B 再切到 C，三扇窗口均停留不到 45 秒。按 `Ctrl+Alt+J`，确认直接回到 B，桌面没有出现操作界面。
2. 在 A 按 `Ctrl+Alt+K`，再切 B、C。按 J 应直接回到 A。打开托盘工作台，确认 A 已清除优先标记。
3. 在 A 按 K，切 B 后再按 K，最后切 C。按 J 应返回 B。关闭标记窗口时，确认 J 能选择其他可用窗口。
4. 在一个窗口停留满 45 秒，再短暂切过另外两扇窗口。没有标记时，按 J 应直接返回停留较长的窗口。
5. 通过托盘打开最近窗口，确认标记出现在同一个列表。搜索窗口标题并点击返回。核对设置和关于页，以及关闭到托盘、暂停记录与退出。
6. 标记最小化前的窗口，确认 J 可以还原目标。用不同 DPI 的第二个显示器检查工作台。
