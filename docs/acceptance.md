# 1.1.0 桌面验收

使用 Windows 11 x64。在装有旧版时，先用托盘或旧版关闭按钮退出，再安装或启动新版。

1. 打开三扇不同应用的窗口。第一扇停留满 45 秒，从第二扇切到第三扇后按 `Ctrl+Alt+J`。确认浮窗在当前屏幕出现，搜索框获焦，第一扇被预选。按回车返回对的窗口，浮窗收起。
2. 改用三个刚访问的窗口，确认浮窗可选中短暂停留的窗口。同一窗口多次进入列表时只出现一次。用应用名搜索，试用方向键、回车、再次按快捷键、Esc 及点击浮窗外。
3. 在两扇不同窗口各按一次 `Ctrl+Alt+K`，确认前台没有被打断。从浮窗按 `Ctrl+Tab` 切到复工栈，返回后重新打开，确认下一个栈顶正确。关闭栈顶对应的原窗口，确认它仍可在工作台手动移除。
4. 关闭工作台，检查托盘仍可打开浮窗和工作台。用托盘暂停后切换应用，确认轨迹没有新增活动。再测试恢复和退出，退出后确认托盘图标和快捷键已释放。
5. 在设置更换快捷键，检查原组合已释放、新组合可用、冲突有反馈。切换外观并重开应用，确认设置持久化。启用随 Windows 登录启动，注销并登录，确认仅托盘常驻。卸载后检查启动项已移除。
6. 在关于页检查更新。分别使用已发布旧版与当前版核对下载链接和无更新状态。断网后检查重试反馈。
7. 把第二个显示器设置为不同缩放比例，验证浮窗在活动窗口所在屏幕完整显示。用浅色、深色和高对比度检查文字、选中态和焦点边框。
