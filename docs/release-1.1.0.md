## 回线 1.1.0

- **快速切换**。按 `Ctrl+Alt+J` 在当前屏幕呼出置顶浮窗。回车就能回到预选窗口，也可用方向键选择或输入标题、应用名搜索。再按一次快捷键、按 Esc 或点到其他应用即可收起。
- **一键留线**。按 `Ctrl+Alt+K` 立即保存当前窗口。浮窗内按 `Ctrl+Tab` 切到复工栈。返回成功才移除栈顶，也可以从工作台添加备注或手动移除失效条目。
- **工作台与托盘**。提供窗口轨迹、复工栈、设置、关于四页。托盘左键快速切换，右键可打开工作台、暂停记录或退出。支持开机后台启动、可修改的全局快捷键和浅色／深色外观。
- **检查更新**。在「关于」检查 GitHub 稳定版，也可以在设置中启用启动时检查。新版本提供安装包下载和版本说明。
- **窗口隐私**。会话里的窗口标题、时长和备注只保存在内存中。应用设置保存在当前用户的本地配置中。

适用于 **Windows 11 x64**。安装包内含运行时，按当前用户安装。升级前可从托盘退出回线。安装包未做代码签名，可用随附的 `.sha256` 文件校验。
